# My Knives — talk illustrations

Slides for a 30-minute talk on working with crew: I am the chef, `lead` is the sous chef, the
workers are station cooks. One 1920×1080 image per section, PNG plus SVG source.

| File | Section |
| --- | --- |
| `01-title` | The craft is in the tools |
| `02-brigade` | The kitchen: chef, sous chef, the 14 stations |
| `03-recipe` | The plan is a recipe |
| `04-kill-resume` | Turn off the computer, lose nothing |
| `05-house-style` | Skills: written down once |
| `06-rhythm` | Plan, build slowly, show, harden |
| `07-quiet-sous-chef` | A sous chef who doesn't talk much |
| `08-throw-away` | Open up before you lock down |

The plan file, feature and commit SHAs in 03, 04 and 07 are examples, not a real run.

Regenerate with `node docs/talk/gen.js` (needs Playwright and Chromium).
